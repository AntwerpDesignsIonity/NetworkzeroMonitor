# Windows Module

Windows-specific implementation of NetworkZero Monitor.

## Requirements

- Windows 10 or higher
- WinPcap or Npcap
- Visual Studio 2019 or higher

## Features

- Native Windows packet capture
- Network adapter enumeration
- Windows-native GUI
- Integration with Windows networking stack

## Building

```bash
# Build using Visual Studio
# Open NetworkzeroMonitor.sln
# Build -> Build Solution
```

## Installation

1. Install WinPcap or Npcap
2. Run the installer or build from source
3. Grant necessary network permissions

## Compatibility

- Windows 10 (64-bit)
- Windows 11
- Windows Server 2019+
